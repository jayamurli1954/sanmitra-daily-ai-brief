# WORLD

### Microsoft Agent Framework hit by a PyPI supply-chain attack
Source: Wiz Blog
https://www.wiz.io/blog/malicious-version-of-microsofts-agent-framework-published-to-pypi

Security researchers at cloud security firm Wiz have discovered two malicious packages uploaded to the Python Package Index impersonating Microsoft's open-source agent-framework repository. Versions 1.26.1 and 1.26.2 contained obfuscated credential-harvesting payloads designed to intercept Azure, GitHub, and development environment credentials. Microsoft has since purged the rogue releases from PyPI, but security analysts advise organizations utilizing agentic frameworks to conduct immediate credential rotations. The incident underscores growing supply-chain vulnerabilities as autonomous AI agents are granted access to enterprise infrastructure.

Source: Hugging Face
https://huggingface.co/apple/FastFrames-L

Apple's machine learning research division has released FastFrames, a family of open weights designed for real-time, interactive video generation. The release features a fourteen-billion parameter flagship model and a compact one-point-three billion parameter variant capable of rendering four-hundred-and-eighty-p video with sub-second latency. Apple also unveiled an optimized LingBot model for camera-conditioned control, demonstrating a sixteen-fold throughput increase over prior baselines. The architecture represents a strategic push by Apple toward on-device, interactive generative creative tools.

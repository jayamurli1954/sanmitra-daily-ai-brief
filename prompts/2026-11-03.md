### Meituan launches LongCat-2.5 multimodal AI model for extended coding tasks
Lead: yes
Source: TechNode
https://technode.com/2026/11/02/meituan-launches-longcat-2-5-multimodal-ai-model-for-extended-coding-tasks/

Meituan released LongCat-2.5 on November 2, adding stronger visual understanding and coding capabilities to its AI model lineup. The model has 1.6 trillion total parameters, with approximately 48 billion activated for each token, and is designed for tasks requiring sustained execution by AI agents. The company said it expanded training on long task sequences and used large-scale reinforcement learning to improve work on complex codebases and complete software projects. It also converts failures encountered by real agents into reproducible training tasks to address gaps in model performance. LongCat-2.5 processes visual and text inputs within a unified token framework, supporting visual coding, creative design, and 3D tasks. The model is available through Meituan’s online chat service and API platform, with GitHub and Hugging Face releases planned to follow.

### Apple confirms Qwen integration for China AI rollout, with beta testing starting November 4
Source: TechNode
https://technode.com/2026/11/02/apple-confirms-qwen-integration-for-china-ai-rollout-with-beta-testing-starting-november-4/

Apple will begin testing Apple Intelligence in mainland China on November 4, integrating Alibaba’s Qwen into Siri, Writing Tools, and Visual Intelligence. The features will arrive through an iOS developer beta before a wider release with iOS 27.3 in December, Apple announced on October 31. Users will be able to ask Qwen questions about text, images, and documents directly within Apple’s system features. They can sign in with a Qwen account or use Sign in with Apple, while Writing Tools will also support generating original content through Qwen. The initial rollout includes live translation, photo cleanup, Genmoji, natural-language photo searches, and summaries of messages, notifications, and recorded conversations. Support for other Apple platforms will follow after the necessary approvals.

### SenseTime open-sources 9-billion-parameter AI model that reuses layers for deeper processing
Source: TechNode
https://technode.com/2026/11/02/sensetime-open-sources-9-billion-parameter-ai-model-that-reuses-layers-for-deeper-processing/

SenseTime has released SenseNova Loop-9B-Preview, an open-source multimodal model that uses repeated computation to extend its processing depth without duplicating the corresponding model weights. The model accepts text and images and generates text for document understanding, coding, and tasks involving external tools. It runs a shared block of 24 decoder layers twice, creating a deeper computation path from a model with approximately nine billion parameters. The documented training setup supports sequences of up to 262,144 tokens and combines text, images, code, and tool-use examples. SenseTime has published model weights, inference instructions, and training guidance, with the project distributed under the Apache 2.0 license.
